# 初蒸馏 Prompt：原始素材 → 知识卡片

## 任务

把一篇原始素材（`raw/articles/<slug>.md`）蒸馏成一张结构化知识卡片（`wiki/cards/<slug>.md`）。

**蒸馏 ≠ 摘要。** 不追求覆盖全文，只提炼三层：观点、方法、论据。原文水，卡片就短，允许很短。

## 卡片格式

```markdown
---
id: <slug>
title: <一句话概括内容，不要照抄原文标题>
source: <公众号/知乎/博客名>
url: <原文链接，没有留空>
date: <YYYY-MM-DD 摄入日期>
tags: [<3-6 个主题标签>]
related: [<相关卡片 id>，没有就空列表]
---

## 核心观点
- <一句完整的话，说清主张是什么>

## 方法论 / 可执行要点
- <原文给出的具体做法、步骤、判断标准；原文没有就整节省略>

## 关键论据
- <支撑观点的事实、案例、数据>

## 我的批注
<永远留空——这是人的领地，Agent 一个字都不写>

## 自检
<自检记录>
```

## 规则（每条都必须遵守）

1. **标签全库对齐**：写 tags 前先列出已有卡片的全部标签，优先复用；只有确实没有对应概念时才造新词。
2. **观点归属必须分清**：原文在转述他人观点（如引用某名人、反驳某言论）时，卡片里必须写明是谁的主张，作者的立场单独标注。
3. **论据标注来源层级**：原文引用的数据写"（原文引用）"，原文自己的经历写"（原文陈述）"；不做二次核实，也不假装核实过。
4. **双向关联**：写完卡片后扫一遍已有卡片的标题和标签，把内容相关的 id 写进 `related`，并**回去更新对方卡片的 related**。
5. **人的内容神圣不可动**：已有卡片里 `## 我的批注` 节的任何内容，以及人对正文的修改，永不覆盖。

## 自检流程（必做，不是形式）

逐条核对卡片的每个"核心观点"和"关键论据"：

1. 回到原文找依据，找不到依据的——删掉或改写。
2. 检查观点归属有没有张冠李戴。
3. 检查有没有把"可能/也许"写成肯定句。
4. 在 `## 自检` 节记录：`已核对 N 条，删除/改写 M 条（简述改了什么）`。

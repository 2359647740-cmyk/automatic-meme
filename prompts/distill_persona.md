# 深度蒸馏 Prompt：知识卡片 → SELF_PERSONA + SELF_MEMORY

> Merge 原则整合自 yourself-skill（增量不覆盖 / 冲突标注 / 证据升级）。

## 输入

- 现有 `persona/SELF_PERSONA.md` 和 `persona/SELF_MEMORY.md`（首次则为空）
- 自上次蒸馏以来**新增或被人修改过**的卡片（对比 `persona/snapshots/` 最近快照，或按 date 判断）

只处理增量。没有增量就直接告诉用户"没有新素材，画像无需更新"，不要为跑而跑。

## 三条铁律（来自 merger 原则）

1. **增量不覆盖**：新认知追加/强化到已有结论后面，不整体重写替换。
2. **冲突标注**：新卡片与已有结论矛盾时，不擅自二选一，用 `[⚠️ 冲突]` 标注两处，在蒸馏摘要里请用户裁决。例外：被人手动修改过的卡片永远优先。
3. **证据升级**：新卡片为已有结论提供了更充分的证据时，强化该结论的表述和置信度，并补充来源卡片 id。

## Persona 的两个维度区

### A 区 · 阅读画像（来自收藏的文章、书籍、帖子）

从卡片的**取舍**里提炼——收藏什么本身就是人格证据：

- 关注议题：反复出现的主题、偏好的尺度（宏观/微观、长期/短期）
- 思维框架：这人用什么工具看世界（类比、模型、外推、第一性原理……）
- 判断偏好：对哪类叙事怀疑/买账，偏好什么论证方式（数据/故事/权威）
- 内容品味：偏好长文深度还是碎片观点，偏好什么来源

每条结论标注来源：`([[卡片id]], [[卡片id]])`。没有依据的维度不要写。

### B 区 · 自我认知（仅当素材包含第一人称内容时启用）

日记、自述、聊天记录（经 `tools/` 解析）这类**本人产出**的素材，按以下维度提取（整合自 yourself-skill 的 self_analyzer）：

- 核心价值观：工作观 / 金钱观 / 关系观 / 成长观 / 核心冲突
- 重要记忆：人生关键节点、转折点及影响
- 成长轨迹：近几年的变化、正在努力的方向、反复挣扎的课题
- 决策与情绪模式：理性/感性、计划/随性、面对失败的反应

规则：有原文依据就引用原话（加引号）；没有信息的维度标注 `（素材不足）`；**不做心理学诊断**，不过度推断。

素材全是第三方文章时，B 区整节标注 `（暂无第一人称素材）`。

## SELF_MEMORY 的组织

按主题分区（如「热力学世界观」「AI 产业与开源」），每条知识标注来源卡片 id。新增量：

- 新主题 → 开新分区
- 已有主题 → 追加到对应分区底部，并标注 `<!-- [追加于 日期，来源：[[卡片id]]] -->`
- 与旧记忆冲突 → 同样 `[⚠️ 冲突]` 标注

## 输出

1. 更新 `SELF_PERSONA.md` 和 `SELF_MEMORY.md`（用 Edit 追加/修改，不整体重写）
2. 快照：复制到 `persona/snapshots/<今天日期>/`
3. 在当日 log 写**蒸馏摘要**：本次新增了什么认知、强化了什么、发现了几处冲突——这是给用户看的"你变了没有"报告

## 首页契约（工作台首页直接消费，每次蒸馏后必须刷新）

`SELF_PERSONA.md` 开头三行是工作台的动态首页：

```markdown
# SELF_PERSONA · 思维模式画像

> 一句话当前评价——基于最近蒸馏数据对这个人的最新判断，随每次蒸馏重写，禁止沿用套话。

一段详细解释：支撑这个评价的具体偏好、框架、张力（2-3 句）。
```

- blockquote 是首页大标题：写"你现在是一个什么样的思考者"，要反映**最近**新增的素材带来的变化（新主题、转向、强化的判断），不是永远正确的通用描述。
- 紧随的段落是首页副文：详细解释评价的依据。
- 趋势数据（近 7/30 天新增、活跃主题、规划进度）由工作台自动计算，不用手写。

## 小节契约（工作台「认知剖面」和「行动」页按小节解析，每次蒸馏后必须维护）

SELF_PERSONA.md 的正文尽量收纳进这些小节（没有素材就留空并注明，不要删节）：

- `## 思维框架`：每条 = `- **名称**：描述。（[[卡片id]]）`，卡片引用是证据链，可点击跳转
- `## 决策模式`：双极量尺，每行严格 `- 左极 ↔ 右极：0-100`（如 `- 理性 ↔ 感性：70`）——不遵守这个格式工作台就画不出量尺；禁止只写单个数值（如"理性 75"）
- `## 绝对不做的事`：红线清单，每条一行
- `## 待验证`：认知盲区，每条一行——行动页会把它们自动变成建议任务
- `## Correction 记录`：每条一行（格式见 correction.md）

B 区的其他维度（核心价值观、重要记忆、成长轨迹等）正常用 `##` 小节书写，工作台会在「完整画像」折叠块展示全文。

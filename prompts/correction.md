# 纠正处理 Prompt

> 整合自 yourself-skill 的 correction_handler。

## 触发识别

用户说以下任何一类话，进入纠正模式：

- "不对" / "不是这样的" / "这不像我"
- "我不会这样想" / "我不会这样说"
- "我应该是…" / "我其实是…"
- "太夸张了" / "我没这么极端" / "这观点不是我的"
- 直接在工作台里改了卡片（不算对话纠正，但同样生效）

## 纠正分类

| 类型 | 例子 | 落到哪 |
|------|------|--------|
| 卡片事实类 | "这篇文章不是这个意思" | 改 `wiki/cards/` 对应卡片 |
| Persona 认知类 | "我不是怀疑论者，我只是重视证据" | 改 `SELF_PERSONA.md` 对应维度 |
| Memory 知识类 | "这个数据记错了" | 改 `SELF_MEMORY.md` 对应分区 |

## 处理流程

1. **确认理解**：
   ```
   我理解了，你是说你不是{旧认知}，而是{新认知}，对吗？
   ```
2. **生成 Correction 记录**，追加到对应文件的 `## Correction 记录` 节。**每条一行 bullet**（工作台按行解析这个节，禁止用 `###` 小节或多行格式）：
   ```markdown
   - Correction #N · YYYY-MM-DD · 位置：{卡片id / Persona 某节 / Memory 某分区} · 原文：{被纠正的描述} → 纠正为：{新的描述} · 用户原话："{原话}"
   ```
3. **同时修改被纠正的原文**，旁边标注 `[已纠正，见 Correction #N]`。
4. **立即生效**：下一条回复就必须体现纠正后的认知。

## 注意

- 不质疑用户的纠正——他们最了解自己。但可以确认理解是否准确，避免误改。
- 被纠正过的内容权重最高：下次 `distill` 遇到与之冲突的卡片结论，以纠正为准。
